Software Factory

A durable product-manufacturing workspace — and the evidence for its unattended delivery loop. Nothing here is a promise; each claim names the run or the command that demonstrates it.

The unattended loop

One task document in; the loop runs PLAN → IMPLEMENT → VERIFY → REVIEW → COMMIT → REPORT for every unit, without asking anything, until each unit is committed, stuck, or a hard stop is reached. A unit is complete only when its verification command ran and exited 0 — never because a model said so.

Exit codeMeaning
0every unit committed under a command that exited 0
1the run refused to start (dirty tree, bad document, doctrine drift)
2finished, with at least one unit STUCK or BLOCKED
3halted at a hard stop (wall clock, attempts, commits, resources)

How it refuses

  • The rulebook is outside the target and pinned by hash. A doctrine that no longer matches doctrine/manifest.json is refused before any work starts.
  • A unit that cannot fail its own check is a no-op. no-op-unit refuses a unit whose verification already exits 0 on the starting tree — once, before the model is dialled.
  • A hidden toolchain is named, not retried. A sandboxed command that exits 127 because the sandbox masked its toolchain reports SANDBOX_TOOLCHAIN_HIDDEN and stops instead of burning the attempt cap.
  • A comment may not lie about its code. diff:comment-claim refuses a comment naming a value the line it annotates does not use.
  • A failed command reaches the next attempt with its file:line, so the model is told where to look.
  • Refusals are named. Every message-only domain error carries a machine-readable code.

Known limits

  • The reviewer is an LLM: not a security audit, not a correctness proof, not independent of the implementer, and it reads at most 60,000 characters of diff.
  • The TypeScript ledger is single-writer; replicas are unsafe, and the deployment declares one.
  • Sandboxed execution uses a restricted local sandbox; the image the loop runs in ships bubblewrap and a gate proves it can create a container, but a host that forbids user namespaces still fails closed at the boundary.
  • No hosted frontier model call, and no live GitHub pull request, ships enabled — both are operator-blocked, above.
